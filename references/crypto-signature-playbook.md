# 签名参数还原 + 加密原语识别（实战方法论）

> 来源：`yasminefolo/reverse-engineering-is-over`（抖音 38.1.0 native 签名库案例：7 个签名参数，
> 30 天还原 6 个、$100 成本，其中含 329 字节三阶段复合参数）+ 本 Skill 工具链映射。
> 适用：接口带 `sign/a_bogus/x-bogus/msToken` 类参数、native 层签名库、被 OLLVM/VMP 挡住的算法还原。

---

## 一、核心方法论（该案例真正有价值的部分）

### 1. 动态优先（当静态被 OLLVM/VMP 挡住时）

**信号**：控制流平坦化（`while-switch` dispatcher）、私有字节码 VM、代码虚拟化。
**结论**：这类目标上静态分析收益极低（案例原话：静态"基本被击败"）→ **切动态观测**：

```
函数输入/输出 hook（Frida 或本机替代方案）
  → 把黑盒函数变成"输入→输出"数据流
  → 用数据流反推算法（分段识别：先定边界，再逐段还原）
```

**本机替代方案**（Frida 未部署到模拟器时的降级链）：
`scripts/emu_check.py`（Unicorn 离线执行函数，`--trace` 看指令流、`--dump` 看写出缓冲）
→ JEB 调试器 / CE（Windows 目标）→ 最后才考虑部署 frida-server 到雷电14（面具已就绪）。

### 2. 逐参数攻坚（不要一次全吃）

案例节奏：**先啃短参数**（5 个短签名参数先还原并**线上验证 30/30**）→ 再啃复合参数（329 字节三阶段）。
- 每个参数独立还原 + 独立验证；验证过再动下一个。
- 复合参数**先分段**：案例的长参数 = Broken-RC4 + ARX sponge + SPECK 密钥派生 三阶段串联 → 分段识别、分段还原、离线对齐后拼接。

### 3. 双轨验证（防"离线对、线上挂"）

| 验证 | 手段 | 判据 |
|---|---|---|
| 离线对齐 | 同输入 → 同输出（钉死随机源） | 逐字节相等（对应 `js-signature-reverse.md` 的算法自检） |
| 线上实测 | 生成的签名实际发请求 | 服务端稳定接受（小流量、低频） |

## 二、加密原语识别速查表（拿到可疑函数先查这个）

| 特征（常量/结构） | 算法 | 定位要点 |
|---|---|---|
| delta `0x9E3779B9` + 32 轮移位 | **XTEA / TEA 家族** | 密钥 128bit，常见于卡密/授权本地算法 |
| 256 字节 KSA 循环 + 变体步进 | **RC4 变体（含 Broken-RC4）** | 案例中作为复合参数第一段 |
| 只有 add/rot/xor、无 S-box、吸收式置换 | **ARX sponge** | 案例第二段；看状态宽度与轮函数 |
| 轮常量/密钥扩展特征明显、64/128bit 分组 | **SPECK / SIMON** | 案例用于密钥派生；注意变体参数 |
| S-box 首字节 `0x63` 或 T-table | **AES** | 查 T-table 定位轮函数 |
| 固定 8 个 IV 常量（`0x67452301...`） | **MD5** | 卡密校验最常见 |
| `0x6A09E667` 家族常量 | **SHA-1/256** | — |
| 国密常量（`0x7380166F` 等）、64 轮 | **SM3/SM4** | 国内平台高频 |
| CRC 多项式表 + 反射位 | **CRC32/CRC64（含 Jones 变体）** | 案例中出现 CRC64-Jones |
| 8×8 位矩阵 + 异或常量 | **GF(2⁸) affine 变换** | 案例中配合 ARX use |
| 自定义字母表的 64 字符表 | **Base64 变种** | 先提取字母表再解码 |
| 大数组 + `_0x` 变量 + 自执行 | **OB 混淆**（不是加密） | 先还原再谈算法 |

**常量定位法（最快的一步）**：在 `idalib-mcp` 里 `find_bytes` 搜常量字节序列 → `xrefs_to` 拿引用点 → 回溯所属函数。

## 四、反面清单（案例给我们的教训）

- ❌ 一上来就静态硬啃 OLLVM/VMP —— 30 天案例直接判定"静态被击败"，动态观测才是主线
- ❌ 一次性还原全部参数 —— 逐参数、逐个验证
- ❌ 只做离线对齐不做线上实测 —— 双轨验证缺一不可
- ❌ 复合参数不分段就整体攻 —— 先分段识别（每段可能都是已知原语）
- ❌ 忘记记录中间观测 —— 每段的输入/输出/常量都落盘（对应本 Skill 证据纪律）
